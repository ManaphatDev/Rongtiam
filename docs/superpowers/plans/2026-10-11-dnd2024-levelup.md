# D&D 2024 Level-Up (Phase 5b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A D&D 2024 character levels up one level at a time to 20 through a guided wizard, the GM decides how far it may go (enforced in the database), and the builder can start a character at a higher level by running the same wizard.

**Architecture:** The sheet gains `hpGains` (Hit Die results per level, read by `derive`) and `levelAllowed` (set by the GM). Pure functions in `src/rulesets/dnd2024/levelup/` list the steps the next level needs (`levelSteps`), check a `LevelDraft` (`validateLevel`) and apply it (`levelUp`), and the result is written to the sheet as per-path `character_patch` ops (`diffOps`). A Svelte wizard (`LevelUp.svelte`) is a lazy `LevelUp` slot on the `RulesetModule`, hosted by `sheets/LevelUpPanel.svelte`; a `BEFORE` trigger on `characters` stops non-GMs from raising `level` past `levelAllowed`.

**Tech Stack:** Svelte 5 (runes), TypeScript, zod 4, Vitest, PGlite (database tests), Playwright, the existing dice director for the HP roll.

**Spec:** `docs/superpowers/specs/2026-10-11-dnd2024-levelup-design.md` (read it first; this plan follows it).

## Global Constraints

- All user-facing strings are Thai; SRD rules text (feature, feat, invocation names and descriptions) stays English.
- Single class only; no level-down; no spell picking in the level-up (spell slots and cantrip/prepared counts come from the class table through `derive`).
- Feature effects beyond what `derive.ts` already computes are NOT automated: they are appended to the `features` text (max 20 000 characters).
- The level gate applies only to `ruleset = 'dnd2024'` and only to non-GMs; a GM may do anything.
- Schema changes only through a new file in `supabase/migrations/`; every policy/trigger change gets a test in `tests/db/`.
- Anything laid over the table carries the class `overlay-ui` (reuse `.sheet-panel`). A ruleset component is loaded once into `$state` (never inside `{#await}`); an async handler that outlives its UI captures the ids/data it needs **before its first `await`**.
- Real `<button>`s with `aria-pressed`/`aria-label`; reuse the builder's `Pick.svelte` / `PickMany.svelte`; colours only through existing CSS tokens. Phone layout is 375×812. Do not add a dependency.
- Git: commit only the files a task names. The working tree has unrelated uncommitted changes (`.claude/launch.json`, `src/routes/Home.svelte`, `src/routes/Room.svelte`): never `git add -A` / `git add .`. Commit messages carry no AI-attribution lines (the user's global rule overrides the harness default).
- zod defaults that nest mutable values use the function form (`.default(() => [])`).

## Review Focus

Inputs and conditions the spec implies but no feature task exercises on its own, most likely first. Each line has a test in the task that owns the code.

1. **A sheet whose level was typed by hand (no `hpGains`, no `choices`) levels up:** earlier levels keep the average HP (gains are back-filled with the average, not shifted), and picks the sheet has no record of don't block the wizard (Task 5, Task 3).
2. **A pick pool smaller than the count the class asks for** (a Wizard proficient in none of Scholar's six skills; a Rogue whose proficient skills are all already Expertise): the count drops to what the pool can give, so the wizard is never stuck (Task 4).
3. **HP rolled, then the player switches to the average:** once a roll is stored the method is locked to it (Task 4 for `validateLevel`, Task 7 for the UI).
4. **A player's patch that touches `level` without GM permission, or `levelAllowed` at all,** is refused by the database even when sent straight to the API (Task 6).
5. **The features text is near its 20 000-character cap** (a player wrote long notes in it): the new level appends feature names only, and never exceeds the cap (Task 5).

```ts
// The bits of SRD prose the level-up reads: Metamagic option names, feat prerequisites, what a feat adds to an
// ability score, invocation prerequisites. Pure; each reader is tested against srd.json.
import type { Srd } from '../data/schema';
import { ABILITIES, ABILITY_TH, type Ability } from '../i18n/th';

const ABILITY_BY_NAME = Object.fromEntries(ABILITIES.map((a) => [ABILITY_TH[a].en.toLowerCase(), a])) as Record<string, Ability>;

/** Open5e leaves markdown in a few names ("**Lessons of the First Ones**"). */
export const plainName = (name: string) => name.replace(/\*/g, '').trim();

/** The options listed under the Sorcerer's "Metamagic Options" feature, in the SRD's (alphabetical) order. */
export function metamagicOptions(srd: Srd): string[] {
  const f = srd.classes.find((c) => c.key === 'sorcerer')?.features.find((x) => x.name === 'Metamagic Options');
  return [...(f?.desc ?? '').matchAll(/^### (.+)$/gm)].map((m) => m[1].trim());
}

/**
 * What a feat adds to ability scores: "Increase your Strength or Dexterity score by 1, to a maximum of 20" names
 * the abilities; "Increase one ability score of your choice by 1, to a maximum of 30" allows any. Null if nothing.
 */
export function featBoost(desc: string): { abilities: Ability[]; max: number } | null {
  const m = /Increase (?:your )?(.+?) scores? (?:of your choice )?by 1, to a maximum of (\d+)/i.exec(desc);
  if (!m) return null;
  const words = m[1].toLowerCase();
  const named = ABILITIES.filter((a) => new RegExp(`\\b${ABILITY_TH[a].en.toLowerCase()}\\b`).test(words));
  return { abilities: named.length ? named : [...ABILITIES], max: Number(m[2]) };
}

/**
 * Whether a character meets a feat prerequisite such as "Level 4+, Strength or Dexterity 13+" or
 * "Level 19+, Spellcasting Feature". Parts the reader doesn't recognise count as met.
 */
export function meetsPrerequisite(text: string | null, level: number, scores: Record<Ability, number>, caster: boolean): boolean {
  if (!text) return true;
  for (const part of text.split(',').map((s) => s.trim())) {
    const lv = /^Level (\d+)\+/i.exec(part);
    if (lv) {
      if (level < Number(lv[1])) return false;
      continue;
    }
    if (/^Spellcasting/i.test(part)) {
      if (!caster) return false;
      continue;
    }
    const ab = /^(.+?) (\d+)\+$/.exec(part);
    if (ab) {
      const names = ab[1].toLowerCase().split(/\s+or\s+/).map((n) => ABILITY_BY_NAME[n]).filter((a): a is Ability => !!a);
      if (names.length && !names.some((a) => scores[a] >= Number(ab[2]))) return false;
    }
  }
  return true;
}

/**
 * Whether a Warlock at `level` who knows `known` invocations may take one with this prerequisite
 * ("Level 5+ Warlock, Pact of the Blade Invocation"). A cantrip requirement can't be checked here (spells are the
 * player's to manage on the sheet) and counts as met.
 */
export function invocationOpen(prereq: string | null, level: number, known: string[]): boolean {
  if (!prereq) return true;
  const lv = /Level (\d+)\+/i.exec(prereq);
  if (lv && level < Number(lv[1])) return false;
  const inv = /,\s*(.+?) Invocation$/i.exec(prereq);
  return !inv || known.map(plainName).includes(inv[1].trim());
}
```

```ts
// What the next level asks of the player, read from the class overlay and the SRD class table, and what is still
// open to pick. Pure; shared by validateLevel(), levelUp() and the step components.
import { z } from 'zod';
import { fightingStyleFeats } from '../builder/helpers';
import type { Srd } from '../data/schema';
import { martialProficient } from '../derive';
import type { Skill } from '../i18n/th';
import type { D2024 } from '../model';
import { CLASS_RULES, type ChoicePoint, type MasteryFilter } from '../overlay';
import { LevelDraftZ, type LevelDraft } from './draft';
import { invocationOpen, metamagicOptions, plainName } from './srdText';

export type LevelStepId = 'hp' | 'subclass' | 'asi' | 'boon' | 'class' | 'review';

export const classOfChar = (c: D2024, srd: Srd) => srd.classes.find((k) => k.key === c.classKey);
export const pointsAt = (c: D2024, level: number): ChoicePoint[] =>
  CLASS_RULES.find((r) => r.key === c.classKey)?.choices.filter((p) => p.level === level) ?? [];

const num = (s: string | undefined) => Number.parseInt(s ?? '', 10) || 0;
/** How much a class-table column grows on reaching `level`. */
const growth = (table: Record<string, string[]>, col: string, level: number) =>
  Math.max(0, num(table[col]?.[level - 1]) - num(table[col]?.[level - 2]));

export interface ClassPicks {
  expertise: number;
  expertiseFrom: Skill[] | null;
  fightingStyle: boolean;
  metamagic: number;
  masteries: number;
  masteryFilter: MasteryFilter;
  invocations: number;
}

/** The class-specific things reaching `level` adds: overlay choice points, and what grows in the class table. */
export function classPicks(c: D2024, srd: Srd, level: number): ClassPicks {
  const cls = classOfChar(c, srd);
  const pts = pointsAt(c, level);
  const exp = pts.find((p) => p.kind === 'expertise');
  const mastery = CLASS_RULES.find((r) => r.key === c.classKey)?.choices.find((p) => p.kind === 'masteries');
  return {
    expertise: exp?.kind === 'expertise' ? exp.count : 0,
    expertiseFrom: exp?.kind === 'expertise' ? exp.from ?? null : null,
    fightingStyle: pts.some((p) => p.kind === 'fightingStyle'),
    metamagic: pts.reduce((n, p) => n + (p.kind === 'metamagic' ? p.count : 0), 0),
    masteries: mastery && cls ? growth(cls.table, 'Weapon Mastery', level) : 0,
    masteryFilter: mastery?.kind === 'masteries' ? mastery.filter : 'any',
    invocations: cls ? growth(cls.table, 'Eldritch Invocations', level) : 0,
  };
}
const hasClassPicks = (p: ClassPicks) => p.fightingStyle || p.expertise + p.metamagic + p.masteries + p.invocations > 0;

/** The wizard steps for reaching level + 1, in order. */
export function levelSteps(c: D2024, srd: Srd): LevelStepId[] {
  const next = c.level + 1;
  const pts = pointsAt(c, next);
  const out: LevelStepId[] = ['hp'];
  if (pts.some((p) => p.kind === 'subclass')) out.push('subclass');
  if (pts.some((p) => p.kind === 'asi' && !p.epicBoon)) out.push('asi');
  if (pts.some((p) => p.kind === 'asi' && p.epicBoon)) out.push('boon');
  if (hasClassPicks(classPicks(c, srd, next))) out.push('class');
  out.push('review');
  return out;
}

// What the sheet records of earlier choices: the builder's draft (5a) and the level drafts (5b). A hand-made sheet
// has neither, and anything unreadable counts as nothing picked.
const PastZ = z.object({
  build: z.object({
    draft: z.object({
      masteries: z.array(z.string()).catch(() => []),
      invocations: z.array(z.string()).catch(() => []),
    }).catch(() => ({ masteries: [], invocations: [] })),
  }).optional().catch(undefined),
  levels: z.array(LevelDraftZ).catch(() => []),
});
const past = (c: D2024) => PastZ.parse(c.choices ?? {});

export const pastLevels = (c: D2024): LevelDraft[] => past(c).levels;

export function pastPicks(c: D2024): { masteries: string[]; invocations: string[]; metamagic: string[] } {
  const p = past(c);
  return {
    masteries: [...(p.build?.draft.masteries ?? []), ...p.levels.flatMap((l) => l.masteries)],
    invocations: [...(p.build?.draft.invocations ?? []), ...p.levels.flatMap((l) => l.invocations)],
    metamagic: p.levels.flatMap((l) => l.metamagic),
  };
}

/** Skills the character is proficient in but not expert at, within `from` when the feature limits it. */
export const expertisePool = (c: D2024, from: Skill[] | null): string[] =>
  Object.entries(c.skills).filter(([k, r]) => r === 1 && (!from || from.includes(k as Skill))).map(([k]) => k);

export const fightingStylePool = (c: D2024, srd: Srd): string[] =>
  fightingStyleFeats(srd).map((f) => f.key).filter((k) => !c.feats.includes(k));

export const metamagicPool = (c: D2024, srd: Srd): string[] => {
  const known = pastPicks(c).metamagic;
  return metamagicOptions(srd).filter((m) => !known.includes(m));
};

export function masteryPool(c: D2024, srd: Srd, filter: MasteryFilter): string[] {
  const known = pastPicks(c).masteries;
  return srd.weapons
    .filter((w) => filter === 'any' || (filter === 'melee' ? !w.ranged : w.simple || martialProficient(c.classKey, w)))
    .map((w) => w.key)
    .filter((k) => !known.includes(k));
}

export function invocationPool(c: D2024, srd: Srd, level: number): string[] {
  const known = pastPicks(c).invocations;
  return (classOfChar(c, srd)?.invocations ?? [])
    .filter((i) => !known.includes(i.name) && invocationOpen(i.prerequisite, level, known))
    .map((i) => i.name);
}

/** A display label for an invocation or option name. */
export const label = plainName;
```

```ts
// Checks one level-up draft against the rules. Every message says how to fix the problem, and is tagged with the
// wizard step that fixes it.
import { repeatable } from '../builder/helpers';
import type { Srd } from '../data/schema';
import { ABILITY_TH, type Ability } from '../i18n/th';
import type { D2024 } from '../model';
import type { LevelDraft } from './draft';
import { featBoost, meetsPrerequisite } from './srdText';
import {
  classOfChar, classPicks, expertisePool, fightingStylePool, invocationPool, levelSteps, masteryPool, metamagicPool,
  type LevelStepId,
} from './steps';

export interface LevelIssue { step: LevelStepId; message: string }

/** General feats other than Ability Score Improvement (which the ASI step offers as its own choice). */
export const generalFeats = (srd: Srd) => srd.feats.filter((f) => f.type === 'general' && f.key !== 'ability-score-improvement');
export const epicBoons = (srd: Srd) => srd.feats.filter((f) => f.type === 'epic boon');
export const isCaster = (c: D2024, srd: Srd) => (classOfChar(c, srd)?.caster ?? 'none') !== 'none';
/** A pick count, capped by how many options are left (so a small pool never leaves the wizard stuck). */
export const needed = (count: number, pool: string[]) => Math.min(count, pool.length);

const exactly = (picked: string[], n: number, pool: string[]) =>
  picked.length === n && new Set(picked).size === n && picked.every((p) => pool.includes(p));

export function validateLevel(c: D2024, d: LevelDraft, srd: Srd, isGM: boolean): LevelIssue[] {
  const cls = classOfChar(c, srd);
  if (!cls) return [{ step: 'review', message: 'อาชีพบนชีทไม่อยู่ใน SRD แก้อาชีพบนชีทก่อน' }];
  if (c.level >= 20) return [{ step: 'review', message: 'ตัวละครอยู่เลเวล 20 แล้ว' }];
  const next = c.level + 1;
  const out: LevelIssue[] = [];
  const add = (step: LevelStepId, message: string) => out.push({ step, message });

  // HP: the method, and a roll that was really made. A stored roll stays: switching to the average would be a re-roll.
  if (d.hp.rolled !== null && d.hp.method !== 'roll') add('hp', 'ทอยไปแล้ว ใช้ผลทอยนั้น');
  else if (!d.hp.method) add('hp', 'เลือกวิธีเพิ่ม HP: ค่าเฉลี่ย หรือทอย Hit Die');
  else if (d.hp.method === 'roll' && !(d.hp.rolled !== null && d.hp.rolled >= 1 && d.hp.rolled <= cls.hitDie)) add('hp', 'ทอย Hit Die ก่อน');

  const steps = levelSteps(c, srd);
  const raise = (a: Ability, by: number, max: number) => c.abilities[a] + by > max;

  if (steps.includes('asi')) {
    const asi = d.asi;
    if (!asi) add('asi', 'เลือกเพิ่มค่าพลัง หรือเลือก feat');
    else if (asi.kind === 'scores') {
      const n = asi.mode === '2' ? 1 : 2;
      if (asi.picks.length !== n || new Set(asi.picks).size !== n) {
        add('asi', asi.mode === '2' ? 'เลือกค่าพลังที่จะ +2' : 'เลือกค่าพลัง 2 ค่าที่จะ +1 (คนละค่า)');
      } else {
        for (const a of asi.picks) if (raise(a, n === 1 ? 2 : 1, 20)) add('asi', `${ABILITY_TH[a].name}จะเกิน 20 ให้เลือกค่าอื่น`);
      }
    } else {
      const f = generalFeats(srd).find((x) => x.key === asi.key);
      if (!f) add('asi', 'เลือก feat');
      else {
        if (!meetsPrerequisite(f.prerequisite, next, c.abilities, isCaster(c, srd))) add('asi', `ยังไม่ผ่านเงื่อนไขของ ${f.name}: ${f.prerequisite}`);
        if (c.feats.includes(f.key) && !repeatable(f)) add('asi', `มี ${f.name} อยู่แล้ว ให้เลือก feat อื่น`);
        const boost = featBoost(f.desc);
        if (boost) {
          if (!asi.ability || !boost.abilities.includes(asi.ability)) add('asi', `เลือกค่าพลังที่ ${f.name} เพิ่มให้`);
          else if (raise(asi.ability, 1, boost.max)) add('asi', `${ABILITY_TH[asi.ability].name}จะเกิน ${boost.max} ให้เลือกค่าอื่น`);
        }
      }
    }
  }

  if (steps.includes('boon')) {
    const f = epicBoons(srd).find((x) => x.key === d.boon?.key);
    if (!f) add('boon', 'เลือก Epic Boon');
    else {
      if (!meetsPrerequisite(f.prerequisite, next, c.abilities, isCaster(c, srd))) add('boon', `ยังไม่ผ่านเงื่อนไขของ ${f.name}: ${f.prerequisite}`);
      if (c.feats.includes(f.key)) add('boon', `มี ${f.name} อยู่แล้ว ให้เลือก Boon อื่น`);
      const boost = featBoost(f.desc);
      const a = d.boon?.ability ?? null;
      if (boost && (!a || !boost.abilities.includes(a))) add('boon', 'เลือกค่าพลังที่จะ +1');
      else if (boost && a && raise(a, 1, boost.max)) add('boon', `${ABILITY_TH[a].name}จะเกิน ${boost.max} ให้เลือกค่าอื่น`);
    }
  }

  if (steps.includes('class')) {
    const p = classPicks(c, srd, next);
    const check = (count: number, picked: string[], pool: string[], message: string) => {
      const n = needed(count, pool);
      if (!exactly(picked, n, pool)) add('class', message.replace('{n}', String(n)));
    };
    if (p.expertise) check(p.expertise, d.expertise, expertisePool(c, p.expertiseFrom), 'เลือกสกิลที่เชี่ยวชาญ (Expertise) ให้ครบ {n} อย่าง จากสกิลที่ชำนาญแล้ว');
    if (p.fightingStyle && fightingStylePool(c, srd).length && !(d.fightingStyle && fightingStylePool(c, srd).includes(d.fightingStyle))) {
      add('class', 'เลือก Fighting Style ที่ยังไม่มี');
    }
    if (p.metamagic) check(p.metamagic, d.metamagic, metamagicPool(c, srd), 'เลือก Metamagic ให้ครบ {n} อย่าง');
    if (p.masteries) check(p.masteries, d.masteries, masteryPool(c, srd, p.masteryFilter), 'เลือกอาวุธสำหรับ Weapon Mastery เพิ่มอีก {n} ชนิด');
    if (p.invocations) check(p.invocations, d.invocations, invocationPool(c, srd, next), 'เลือก Eldritch Invocation เพิ่มอีก {n} อย่าง');
  }

  if (!isGM && next > (c.levelAllowed ?? c.level)) add('review', `GM ยังไม่อนุญาตให้ขึ้นเลเวล ${next}`);
  return out;
}
```

```ts
// Applies one checked level-up draft to a character, touching only what a level changes (level, HP, scores, feats,
// Expertise, subclass, the features text, the record of choices), and turns the change into per-path sheet patches
// so a concurrent edit of another field is not overwritten.
import type { CharOp } from '../../../sync/types';
import type { Srd } from '../data/schema';
import { derive } from '../derive';
import { ABILITY_TH, SKILLS, type Skill } from '../i18n/th';
import type { D2024 } from '../model';
import type { LevelDraft } from './draft';
import { classOfChar, pastLevels, pointsAt, label } from './steps';
import { validateLevel } from './validate';

export class LevelUpError extends Error {}

const FEATURES_MAX = 20000;

/** The features text for reaching `level`: SRD features of the class (and subclass), then what was picked. */
export function levelText(c: D2024, d: LevelDraft, srd: Srd, level: number, full: boolean): string {
  const cls = classOfChar(c, srd)!;
  const sub = cls.subclasses.find((s) => s.key === c.subclass);
  const feats = [...cls.features, ...(sub?.features ?? [])].filter((f) => f.levels.includes(level));
  const out = [`# เลเวล ${level}`, ...feats.map((f) => (full ? `${f.name}: ${f.desc}` : f.name))];
  const name = (k: string) => srd.feats.find((f) => f.key === k)?.name ?? k;
  const asi = d.asi;
  if (asi?.kind === 'scores') {
    const by = asi.mode === '2' ? 2 : 1;
    out.push(`ค่าพลัง: ${asi.picks.map((a) => `${ABILITY_TH[a].name} +${by}`).join(', ')}`);
  }
  if (asi?.kind === 'feat' && asi.key) out.push(`Feat: ${name(asi.key)}`);
  if (d.boon?.key) out.push(`Epic Boon: ${name(d.boon.key)}`);
  if (d.fightingStyle) out.push(`Fighting Style: ${name(d.fightingStyle)}`);
  if (d.expertise.length) out.push(`Expertise: ${d.expertise.map((s) => SKILLS[s as Skill]?.th ?? s).join(', ')}`);
  if (d.masteries.length) out.push(`Weapon Mastery: ${d.masteries.map((k) => srd.weapons.find((w) => w.key === k)?.name ?? k).join(', ')}`);
  if (d.invocations.length) out.push(`Eldritch Invocation: ${d.invocations.map(label).join(', ')}`);
  if (d.metamagic.length) out.push(`Metamagic: ${d.metamagic.join(', ')}`);
  return out.join('\n');
}

/** Appends a level's text: in full if it fits under the cap, else the feature names only, never past the cap. */
export function appendFeatures(existing: string, full: string, names: string): string {
  const sep = existing ? '\n\n' : '';
  if (existing.length + sep.length + full.length <= FEATURES_MAX) return existing + sep + full;
  return (existing + sep + names).slice(0, FEATURES_MAX);
}

export function levelUp(c: D2024, d: LevelDraft, srd: Srd, isGM: boolean): D2024 {
  const issues = validateLevel(c, d, srd, isGM);
  if (issues.length) throw new LevelUpError(issues.map((i) => i.message).join('\n'));
  const cls = classOfChar(c, srd)!;
  const level = c.level + 1;
  const n = structuredClone(c);
  n.level = level;

  // Levels before this one keep what they had; a hand-made sheet without gains keeps the average for each.
  const average = cls.hitDie / 2 + 1;
  n.hpGains = [...Array.from({ length: level - 2 }, (_, i) => c.hpGains[i] ?? average), d.hp.method === 'roll' ? d.hp.rolled! : average];

  if (pointsAt(c, level).some((p) => p.kind === 'subclass') && !n.subclass && cls.subclasses[0]) n.subclass = cls.subclasses[0].key;

  if (d.asi?.kind === 'scores') {
    for (const a of d.asi.picks) n.abilities[a] += d.asi.mode === '2' ? 2 : 1;
    n.feats.push('ability-score-improvement');
  } else if (d.asi?.kind === 'feat' && d.asi.key) {
    n.feats.push(d.asi.key);
    if (d.asi.ability) n.abilities[d.asi.ability] += 1;
  }
  if (d.boon?.key) {
    n.feats.push(d.boon.key);
    if (d.boon.ability) n.abilities[d.boon.ability] += 1;
  }
  if (d.fightingStyle) n.feats.push(d.fightingStyle);
  for (const s of d.expertise) n.skills[s as Skill] = 2;

  n.features = appendFeatures(c.features, levelText(n, d, srd, level, true), levelText(n, d, srd, level, false));
  n.choices = { ...c.choices, levels: [...pastLevels(c), d] };

  // The new hit points arrive unhurt: current HP grows by what max HP grew (a GM override of max HP gives nothing).
  n.hp.current = c.hp.current + Math.max(0, derive(n, srd).maxHp - derive(c, srd).maxHp);
  return n;
}

const isObject = (v: unknown): v is Record<string, unknown> => !!v && typeof v === 'object' && !Array.isArray(v);

/** Per-path patches that turn `before` into `after`: objects are walked, arrays and values replaced, null removes. */
export function diffOps(before: unknown, after: unknown, path: (string | number)[] = []): CharOp[] {
  if (isObject(before) && isObject(after)) {
    const keys = [...new Set([...Object.keys(before), ...Object.keys(after)])];
    return keys.flatMap((k) => diffOps(before[k], after[k], [...path, k]));
  }
  if (JSON.stringify(before) === JSON.stringify(after)) return [];
  return [{ path, value: after === undefined ? null : after }];
}
```

```sql
-- Phase 5b: a D&D 2024 character's level is the GM's call. A player creates characters at most at the room's start
-- level (rooms.settings.startLevel, default 1), levels up one step at a time only up to data.levelAllowed, and can
-- never change levelAllowed. GMs, other rulesets and trusted RPCs (current_user <> 'authenticated') pass.

-- A jsonb number as an int, or the fallback for anything else (missing, null, text...).
create or replace function private.json_int(v jsonb, fallback int) returns int
language sql immutable set search_path = '' as $$
  select case when jsonb_typeof(v) = 'number' then floor((v #>> '{}')::numeric)::int else fallback end
$$;
grant execute on function private.json_int(jsonb, int) to authenticated;

-- Security invoker, like members_guard: current_user tells a player's own write from a trusted RPC.
create or replace function private.characters_level_guard() returns trigger
language plpgsql set search_path = '' as $$
declare
  lv_old int;
  lv_new int;
  allowed int;
  start_level int;
begin
  if new.ruleset <> 'dnd2024' or current_user <> 'authenticated' or private.is_gm(new.room_id) then
    return new;
  end if;
  lv_new := private.json_int(new.data -> 'level', 1);

  if tg_op = 'INSERT' then
    select private.json_int(r.settings -> 'startLevel', 1) into start_level from public.rooms r where r.id = new.room_id;
    start_level := coalesce(start_level, 1);
    if lv_new > start_level or private.json_int(new.data -> 'levelAllowed', 1) > start_level then
      raise exception 'level above the room start level' using errcode = '42501';
    end if;
    return new;
  end if;

  if (new.data -> 'levelAllowed') is distinct from (old.data -> 'levelAllowed') then
    raise exception 'only a GM can allow levels' using errcode = '42501';
  end if;
  lv_old := private.json_int(old.data -> 'level', 1);
  allowed := private.json_int(old.data -> 'levelAllowed', lv_old);
  if lv_new <> lv_old and (lv_new <> lv_old + 1 or lv_new > allowed) then
    raise exception 'level change not allowed' using errcode = '42501';
  end if;
  return new;
end $$;
grant execute on function private.characters_level_guard() to authenticated;

create trigger characters_level_guard before insert or update on public.characters
  for each row execute function private.characters_level_guard();
```

Create `src/rulesets/dnd2024/levelup/persist.ts`:

```ts
// The unfinished level-up, kept in this browser per character, so closing the panel or reloading mid-roll neither
// loses it nor buys a second HP roll. A draft for another level, or anything unreadable, is dropped.
import { z } from 'zod';
import { LevelDraftZ, emptyLevelDraft, type LevelDraft } from './draft';

export interface SavedLevel { step: number; draft: LevelDraft }

const SavedZ = z.object({ v: z.literal(1), step: z.number().int().min(0).max(10), draft: LevelDraftZ });
const key = (id: string) => `rongtiam:levelup:${id}`;

export function loadLevelDraft(id: string, forLevel: number): SavedLevel {
  try {
    const text = localStorage.getItem(key(id));
    if (text) {
      const r = SavedZ.safeParse(JSON.parse(text));
      if (r.success && r.data.draft.forLevel === forLevel) return { step: r.data.step, draft: r.data.draft };
    }
  } catch {
    // unreadable or blocked storage: start over
  }
  return { step: 0, draft: emptyLevelDraft(forLevel) };
}

export function saveLevelDraft(id: string, s: SavedLevel): void {
  try {
    localStorage.setItem(key(id), JSON.stringify({ v: 1, ...s }));
  } catch {
    // private mode / quota: the draft just won't survive a reload
  }
}

export function clearLevelDraft(id: string): void {
  try {
    localStorage.removeItem(key(id));
  } catch {
    // ignore
  }
}
```

```svelte
  // one batch of sheet patches at the end. All rules live in validateLevel()/levelUp(); this only shows them.
  import { tick } from 'svelte';
  import type { LevelUpProps } from '../../core/types';
  import { getSrd } from '../index';
  import { parseCharacter } from '../model';
  import { diffOps, levelUp } from './apply';
  import type { LevelDraft } from './draft';
  import { clearLevelDraft, loadLevelDraft, saveLevelDraft } from './persist';
  import { classOfChar, levelSteps, type LevelStepId } from './steps';

  import SubclassStep from './steps/SubclassStep.svelte';
  import { validateLevel } from './validate';

  let { id, data, isGM, rollDice, apply, onClose }: LevelUpProps = $props();

  const srd = getSrd();
  // Mounted once per character and level (the host keys it), so the character being levelled is read once.
  // svelte-ignore state_referenced_locally
  const c = parseCharacter(data);
  const cls = classOfChar(c, srd);
  const next = c.level + 1;
  // svelte-ignore state_referenced_locally
  const saved = loadLevelDraft(id, next);
  let draft = $state(saved.draft);
  let step = $state(saved.step);
  let reached = $state(saved.step);
  let rolling = $state(false);
  let error = $state('');
  let panel = $state<HTMLElement>();
  let heading = $state<HTMLElement>();

  const LABELS: Record<LevelStepId, string> = {
    hp: 'HP', subclass: 'สายอาชีพ', asi: 'ค่าพลัง / feat', boon: 'Epic Boon', class: 'ความสามารถอาชีพ', review: 'ตรวจสอบ',
  };
  const steps = levelSteps(c, srd);
  const at = $derived(Math.min(step, steps.length - 1));
  const current = $derived(steps[at]);
  const all = $derived(validateLevel(c, draft, srd, isGM));
  const mine = $derived(all.filter((i) => i.step === current));
  const con = Math.floor((c.abilities.con - 10) / 2);

  $effect(() => {
    saveLevelDraft(id, { step, draft: $state.snapshot(draft) as LevelDraft });
  });
  $effect(() => {
    panel?.focus();
  });

  function go(to: number) {
    step = Math.max(0, Math.min(to, steps.length - 1));
    reached = Math.max(reached, step);
    void tick().then(() => heading?.focus());
  }
  const jump = (s: LevelStepId) => go(steps.indexOf(s));

  async function rollHp() {
    if (rolling || draft.hp.rolled !== null || !cls) return;
    rolling = true;
    error = '';
    // Captured before the first await: the panel may close while the dice roll, and the result must still be kept.
    const key = id;
    const startedOn = step;
    const target = draft;
    const die = cls.hitDie;

      const r = await rollDice('HP', `1d${die}`, (result) => {
        if (!keep(result.total)) return;
        const kept = $state.snapshot(target) as LevelDraft;
        kept.hp = { method: 'roll', rolled: result.total };
        saveLevelDraft(key, { step: startedOn, draft: kept });
      });
      if (keep(r.total)) target.hp = { method: 'roll', rolled: r.total };
      else error = 'ผลทอยผิดปกติ ลองทอยใหม่';
    } catch {
      // the table already told the player the roll failed
    } finally {
      rolling = false;
    }
  }

    error = '';
    try {
      const n = levelUp(c, $state.snapshot(draft) as LevelDraft, srd, isGM);
      clearLevelDraft(id);
      apply(diffOps(c, n));
    } catch (e) {
      error = (e as Error).message;
    }
  }

    if (e.key === 'Escape') {
      e.stopPropagation();
      onClose();
    }
  }
</script>
```

```svelte
<script lang="ts">
  // Hosts a ruleset's level-up over the table: loads its component once, rolls dice for it and writes each level to
  // the sheet. It stays open, one level after another, until the character reaches the level it was opened for,
  // then shows the sheet again.
  import type { Component } from 'svelte';
  import type { DiceDirector } from '../dice/director';
  import type { LevelUpProps } from '../rulesets/core/types';
  import type { RulesetHost } from '../rulesets/host.svelte';
  import type { RoomStore } from '../sync/room.svelte';
  import type { CharOp, RollResult } from '../sync/types';
  import type { Ui } from '../table/ui.svelte';

  let { store, ui, host, dice }: { store: RoomStore; ui: Ui; host: RulesetHost; dice: DiceDirector } = $props();

  const c = $derived.by(() => {
    void store.charactersVersion;
    return ui.levelUpOpen ? store.state.character(ui.levelUpOpen) : undefined;
  });
  const level = $derived(Number(c?.data.level ?? 1));

  /** The level this visit goes to: what the GM allowed, or one more level when a GM opens it directly. */
  let target = $state(0);
  $effect(() => {
    if (!ui.levelUpOpen) target = 0;
    else if (c && target === 0) {
      const allowed = Number(c.data.levelAllowed ?? level);
      target = Math.min(20, store.isGM ? Math.max(allowed, level + 1) : allowed);
    }
  });
  // Done: back to the sheet. Gone (deleted, made secret): just close.
  $effect(() => {
    if (ui.levelUpOpen && c && target && level >= target) {
      ui.sheetOpen = c.id;
      ui.levelUpOpen = null;
    }
  });
  $effect(() => {
    if (ui.levelUpOpen && store.state.loaded && !c) ui.levelUpOpen = null;
  });
  // Opening a sheet puts the wizard away; its draft is kept for next time.
  $effect(() => {
    if (ui.sheetOpen && ui.levelUpOpen) ui.levelUpOpen = null;
  });

  // Loaded once into state (never inside {#await}), so data changes don't remount it and drop its focus.
  let LevelUp = $state<Component<LevelUpProps> | null>(null);
  let failed = $state(false);
  let attempt = $state(0);
  let loadedFor = '';
  $effect(() => {
    void attempt;
    const ruleset = c?.ruleset;
    if (!ui.levelUpOpen || !ruleset || loadedFor === ruleset) return;
    loadedFor = ruleset;
    LevelUp = null;
    failed = false;
    host.ensure(ruleset).then((m) => m?.LevelUp?.()).then(
      (C) => {
        if (loadedFor !== ruleset) return;
        if (C) LevelUp = C;
        else failed = true;
      },
      () => {
        if (loadedFor === ruleset) failed = true;
      },
    );
  });
  function retry() {
    loadedFor = '';
    attempt++;
  }

  function apply(ops: CharOp[]) {
    if (!c) return;
    for (const o of ops) store.patchCharacter(c.id, o.path, o.value);
  }
  async function rollDice(label: string, expr: string, onDecided?: (result: RollResult) => void): Promise<RollResult> {
    try {
      return (await dice.roll(expr, false, label, onDecided)).result;
    } catch (e) {
      ui.showToast('ทอยไม่สำเร็จ', undefined, (e as Error).message);
      throw e;
    }
  }
  const close = () => (ui.levelUpOpen = null);
</script>

{#if ui.levelUpOpen && c}
  {#if LevelUp}
    <!-- A fresh wizard for every level: its draft and steps belong to that level. -->
    {#key `${c.id}:${level}`}
      <LevelUp ctx={host.ctx} id={c.id} data={c.data} isGM={store.isGM} {rollDice} {apply} onClose={close} />
    {/key}
  {:else}
    <section class="sheet-panel overlay-ui" aria-label="ตัวช่วยขึ้นเลเวล">
      <header class="sheet-bar">
        <h2>ขึ้นเลเวล</h2>
        <button class="btn small" type="button" onclick={close}>ปิด</button>
      </header>
      <div class="sheet-body">
        {#if failed}
          <p class="hint err" role="alert">โหลดตัวช่วยขึ้นเลเวลไม่สำเร็จ</p>
          <button class="btn" type="button" onclick={retry}>ลองใหม่</button>
        {:else}
          <div class="spinner" role="status" aria-label="กำลังโหลด…"></div>
        {/if}
      </div>
    </section>
  {/if}
{/if}
```
