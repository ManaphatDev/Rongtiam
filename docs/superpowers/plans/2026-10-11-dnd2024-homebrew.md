# D&D 2024 Room Homebrew (Phase 5c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GM creates weapons, armor, items, spells, feats, species and backgrounds for their D&D room, and they appear wherever SRD data is used (builder, level-up, sheet), with export/import between rooms.

**Architecture:** One `room_content` row per homebrew entry (`kind: 'hb-<type>'`, `key: 'hb-<slug>'`), validated by per-kind zod schemas in `src/rulesets/dnd2024/homebrew/kinds.ts`. `srdFor(ctx)` (`homebrew/merge.ts`) returns the SRD with the room's valid entries appended, cached by the identity of the rows' `data` objects; every consumer that called `getSrd()` switches to it. A GM editor (`HomebrewEditor.svelte`) drives generic forms from field descriptors and exports/imports a `tabletop-homebrew` file. No database migration.

**Tech Stack:** Svelte 5 (runes), TypeScript, zod 4, Vitest, PGlite (database tests), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-11-dnd2024-homebrew-design.md` (read it first; this plan follows it).

## Global Constraints

- All user-facing strings are Thai; SRD rules text stays English. GM-written text is always shown as plain text (never `{@html}`).
- No migration: writes go through the existing GM-only `room_content` RLS (`store.saveContent(kind, key, data)`, `store.deleteContent(id)`).
- Kinds: `hb-weapon`, `hb-armor`, `hb-item`, `hb-spell`, `hb-feat`, `hb-species`, `hb-background`. Keys match `^hb-[a-z0-9-]{1,60}$` and never change after creation. At most 200 entries per kind.
- Weapons/armor carry `bonus` 0..3 that the sheet computes; other items are name + description only.
- Homebrew species have no sub-choices in the builder. Classes/subclasses are out of scope.
- Export file: `{ format: 'tabletop-homebrew', ruleset: 'dnd2024', schemaVersion: 1, items: [{ kind, key, data }] }`, at most 1 MB on import.
- Anything laid over the table carries the class `overlay-ui`; real `<button>`s; destructive actions use `ui/TwoStepButton.svelte`; colours only through existing CSS tokens; phone layout 375×812; no new dependency.
- Git: commit only the files a task names. The working tree has unrelated uncommitted changes (`.claude/launch.json`, `src/routes/Home.svelte`, `src/routes/Room.svelte`): never `git add -A` / `git add .`. Commit messages carry no AI-attribution lines.
- zod defaults that nest mutable values use the function form.

## Review Focus

1. **A homebrew entry the sheet references is deleted or becomes invalid:** the sheet keeps the key, shows "ไม่พบ (ถูกลบจาก homebrew)", derive ignores it, nothing throws (Task 1 derive test, Task 4 sheet behaviour).
2. **A homebrew background names an Origin feat that does not exist** (deleted feat, typo in an imported file): the background is treated as broken (skipped with an issue), so the builder never crashes on `backgroundFeat(...)!` (Task 3).
3. **Imported file is junk** (not JSON, wrong format, over 1 MB, items with bad keys or kinds, a valid item next to a broken one): import reports a Thai error or skips the bad items and keeps the good ones (Task 5).
4. **A homebrew species in the builder** (no `SPECIES_RULES` entry): every builder path that assumed rules exist (fixtures, validate, build, SpeciesStep) works with no choices (Task 4).
5. **The same `data` arriving twice / content unchanged:** `srdFor` returns the identical object (no recompute, and `viewOf`'s cache stays warm); a changed row yields a new object (Task 3).

```ts
// The room's homebrew: which kinds there are, what a GM fills in for each (form-friendly, validated by zod), and
// how each entry becomes the same shape as the SRD's data so the builder, level-up and sheet use it unchanged.
import { z } from 'zod';
import { parse as parseDice } from '../../../dice/model';
import {
  AbilityZ, type EquipmentOption, type SrdArmor, type SrdBackground, type SrdSpecies, type SrdSpell, type SrdWeapon,
} from '../data/schema';
import type { Srd } from '../data/schema';
import { SKILLS } from '../i18n/th';

export const HB_KINDS = ['weapon', 'armor', 'item', 'spell', 'feat', 'species', 'background'] as const;
export type HbKind = (typeof HB_KINDS)[number];

export const rowKind = (k: HbKind) => `hb-${k}`;
export const kindOfRow = (kind: string): HbKind | null => {
  const k = kind.startsWith('hb-') ? kind.slice(3) : '';
  return (HB_KINDS as readonly string[]).includes(k) ? (k as HbKind) : null;
};
export const HB_KEY = /^hb-[a-z0-9-]{1,60}$/;
export const MAX_PER_KIND = 200;
export const isHomebrew = (key: string) => key.startsWith('hb-');

/** "Flame Tongue" → "hb-flame-tongue", made unique against `taken`. A name with no Latin letters becomes "hb-item". */
export function slugKey(name: string, taken: string[]): string {
  const base = name.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '').slice(0, 50) || 'item';
  let key = `hb-${base}`;
  for (let i = 2; taken.includes(key); i++) key = `hb-${base}-${i}`;
  return key;
}

  z.string().trim().min(1, 'ใส่ข้อความ').max(max, `ยาวได้ไม่เกิน ${max} ตัวอักษร`);
const optText = (max: number) =>
  z.string().trim().max(max, `ยาวได้ไม่เกิน ${max} ตัวอักษร`).nullable().transform((s) => (s ? s : null));
const int = (min: number, max: number) =>
  z.number({ error: 'ใส่ตัวเลข' }).int('ใส่จำนวนเต็ม').min(min, `ไม่น้อยกว่า ${min}`).max(max, `ไม่เกิน ${max}`);

  desc: text(4000), repeatable: z.boolean(),

});
const HbSpeciesZ = z.object({

  properties: [...d.properties], versatile: d.versatile,
  range: d.rangeNormal ? [d.rangeNormal, d.rangeLong ?? d.rangeNormal] : null, mastery: d.mastery, bonus: d.bonus,
});

export const toSrdSpell = (key: string, d: HbSpell): SrdSpell => {

  return { key, ...rest, damageTypes: damageType ? [damageType.toLowerCase()] : [] };

export function toSrdBackground(key: string, d: HbBackground, featName: string): SrdBackground {
  const fixed = d.toolsFixed.map((t) => t.name);
  const choose = d.toolsChooseCount > 0 ? { count: d.toolsChooseCount, label: d.toolsChooseLabel ?? 'เครื่องมือ' } : null;
  const options: EquipmentOption[] = [
    { id: 'A', items: d.gear.map((g) => ({ name: g.name, qty: g.qty, kind: 'gear' as const })), gp: d.gearGold },
    { id: 'B', items: [], gp: d.gold },
  ];
  return {
    key, name: d.name, abilities: [...d.abilities], feat: featName, skills: [...d.skills],
    tool: [...fixed, ...(choose ? [`${choose.label} ×${choose.count}`] : [])].join(', '),
    equipment: [...d.gear.map((g) => `${g.name} ×${g.qty}`), `${d.gearGold} GP`].join(', '),
    tools: { fixed, choose }, equipmentOptions: options,
  };
}
```

```ts
// The SRD as this room sees it: the SRD's data with the room's valid homebrew appended. Rows that don't validate
// are skipped and listed (the GM's editor flags them). The result is cached by the identity of the rows' `data`
// objects: content rows are replaced, never mutated, and the host builds a fresh `ctx.content` array on every read.
import type { RulesetContext } from '../../core/types';
import type { Srd } from '../data/schema';
import { getSrd } from '../index';
import {
  HB_KEY, HB_SCHEMAS, MAX_PER_KIND, issuesOf, kindOfRow, toSrdArmor, toSrdBackground, toSrdFeat, toSrdSpecies,
  toSrdSpell, toSrdWeapon, type HbBackground, type HbKind, type RoomItem,
} from './kinds';

type Row = RulesetContext['content'][number];
export interface BrokenRow { kind: string; key: string; issues: string[] }
export interface Merged { srd: Srd; items: RoomItem[]; broken: BrokenRow[] }

let last: { base: Srd; refs: object[]; merged: Merged } | null = null;

export function merge(base: Srd, content: Row[]): Merged {
  const rows = content.filter((r) => r.kind.startsWith('hb-')).sort((a, b) => a.key.localeCompare(b.key));
  const refs = rows.map((r) => r.data);
  if (last && last.base === base && last.refs.length === refs.length && last.refs.every((d, i) => d === refs[i])) return last.merged;

  const broken: BrokenRow[] = [];
  const ok: Record<HbKind, { key: string; data: unknown }[]> = {
    weapon: [], armor: [], item: [], spell: [], feat: [], species: [], background: [],
  };
  for (const r of rows) {
    const kind = kindOfRow(r.kind);
    if (!kind) {
      broken.push({ kind: r.kind, key: r.key, issues: ['ไม่รู้จักชนิดนี้'] });
      continue;
    }
    if (!HB_KEY.test(r.key)) {
      broken.push({ kind: r.kind, key: r.key, issues: ['key ต้องขึ้นต้นด้วย hb- และมีแต่ a-z 0-9 -'] });
      continue;
    }
    if (ok[kind].length >= MAX_PER_KIND) continue;
    const p = HB_SCHEMAS[kind].safeParse(r.data);
    if (p.success) ok[kind].push({ key: r.key, data: p.data });
    else broken.push({ kind: r.kind, key: r.key, issues: issuesOf(p.error) });
  }

  let merged: Merged;
  if (!rows.length) merged = { srd: base, items: [], broken };
  else {
    const feats = [...base.feats, ...ok.feat.map((e) => toSrdFeat(e.key, e.data as never))];
    const backgrounds = [...base.backgrounds];
    for (const e of ok.background) {
      const d = e.data as HbBackground;
      const feat = feats.find((f) => f.key === d.feat && f.type === 'origin');
      if (feat) backgrounds.push(toSrdBackground(e.key, d, feat.name));
      else broken.push({ kind: 'hb-background', key: e.key, issues: [`ไม่พบ Origin feat "${d.feat}"`] });
    }
    merged = {
      srd: {
        ...base,
        weapons: [...base.weapons, ...ok.weapon.map((e) => toSrdWeapon(e.key, e.data as never))],
        armor: [...base.armor, ...ok.armor.map((e) => toSrdArmor(e.key, e.data as never))],
        spells: [...base.spells, ...ok.spell.map((e) => toSrdSpell(e.key, e.data as never))],
        feats,
        species: [...base.species, ...ok.species.map((e) => toSrdSpecies(e.key, e.data as never))],
        backgrounds,
      },
      items: ok.item.map((e) => ({ key: e.key, ...(e.data as { name: string; desc: string }) })),
      broken,
    };
  }
  last = { base, refs, merged };
  return merged;
}

export const srdFor = (ctx: RulesetContext): Srd => merge(getSrd(), ctx.content).srd;
export const roomItems = (ctx: RulesetContext): RoomItem[] => merge(getSrd(), ctx.content).items;
export const brokenRows = (ctx: RulesetContext): BrokenRow[] => merge(getSrd(), ctx.content).broken;
```

```ts
// The room's homebrew as a file, to carry it to another room. An imported file is untrusted: it is size-checked,
// shape-checked, and every item is validated like a row before anything is written; the GM sees the plan first.
import type { Srd } from '../data/schema';
import { HB_KEY, HB_SCHEMAS, issuesOf, kindOfRow } from './kinds';
import { merge } from './merge';

export const HB_FORMAT = 'tabletop-homebrew';
export const MAX_FILE_BYTES = 1_000_000;

type Row = { kind: string; key: string; data: Record<string, unknown> };
export interface HbFileItem { kind: string; key: string; data: Record<string, unknown> }
export interface HbFile { format: typeof HB_FORMAT; ruleset: 'dnd2024'; schemaVersion: 1; items: HbFileItem[] }
export interface ImportPlan { add: HbFileItem[]; replace: HbFileItem[]; skip: { kind: string; key: string; reason: string }[] }

export class HbFileError extends Error {}

export const toHbFile = (content: Row[]): HbFile => ({
  format: HB_FORMAT, ruleset: 'dnd2024', schemaVersion: 1,
  items: content.filter((r) => r.kind.startsWith('hb-')).map((r) => ({ kind: r.kind, key: r.key, data: r.data })),
});

const isObject = (v: unknown): v is Record<string, unknown> => !!v && typeof v === 'object' && !Array.isArray(v);

export function fromHbText(text: string): HbFile {
  if (text.length > MAX_FILE_BYTES) throw new HbFileError('ไฟล์ใหญ่เกิน 1 MB');
  let f: unknown;
  try {
    f = JSON.parse(text);
  } catch {
    throw new HbFileError('อ่านไฟล์ไม่ออก ไฟล์ต้องเป็น JSON ที่ส่งออกจาก homebrew');
  }
  if (!isObject(f) || f.format !== HB_FORMAT) throw new HbFileError('ไฟล์นี้ไม่ใช่ไฟล์ homebrew');
  if (f.ruleset !== 'dnd2024') throw new HbFileError('ไฟล์นี้เป็น homebrew ของระบบกฎอื่น');
  if (!Array.isArray(f.items)) throw new HbFileError('ไฟล์ homebrew ไม่มีรายการของ');
  const items = f.items.filter((i): i is HbFileItem =>
    isObject(i) && typeof i.kind === 'string' && typeof i.key === 'string' && isObject(i.data));
  return { format: HB_FORMAT, ruleset: 'dnd2024', schemaVersion: 1, items };
}

/** What importing would do. A background's feat may come from the room or from the same file. */
export function planImport(file: HbFile, base: Srd, content: Row[]): ImportPlan {
  const plan: ImportPlan = { add: [], replace: [], skip: [] };
  const valid: HbFileItem[] = [];
  for (const i of file.items) {
    const kind = kindOfRow(i.kind);
    if (!kind) plan.skip.push({ kind: i.kind, key: i.key, reason: 'ไม่รู้จักชนิดนี้' });
    else if (!HB_KEY.test(i.key)) plan.skip.push({ kind: i.kind, key: i.key, reason: 'key ไม่ถูกรูปแบบ' });
    else {
      const p = HB_SCHEMAS[kind].safeParse(i.data);
      if (p.success) valid.push(i);
      else plan.skip.push({ kind: i.kind, key: i.key, reason: issuesOf(p.error).join('; ') });
    }
  }
  // Merge the room and the valid file items together to see which backgrounds resolve their feat.
  const byKey = new Map(content.filter((r) => r.kind.startsWith('hb-')).map((r) => [`${r.kind}/${r.key}`, r]));
  for (const i of valid) byKey.set(`${i.kind}/${i.key}`, { ...i, data: { ...i.data } });
  const broken = new Set(merge(base, [...byKey.values()]).broken.map((b) => `${b.kind}/${b.key}`));
  for (const i of valid) {
    if (broken.has(`${i.kind}/${i.key}`)) plan.skip.push({ kind: i.kind, key: i.key, reason: 'อ้างถึงของที่ไม่มี (เช่น Origin feat)' });
    else if (content.some((r) => r.kind === i.kind && r.key === i.key)) plan.replace.push(i);
    else plan.add.push(i);
  }
  return plan;
}
```

```ts
// How many characters use a key, so deleting a homebrew entry can say who it affects. Reads raw sheet data
// defensively: a character missing a field simply doesn't use the key there.
const has = (v: unknown, key: string) => (Array.isArray(v) ? v.includes(key) : v === key);

export function usageCount(key: string, characters: Record<string, unknown>[]): number {
  return characters.filter((d) => {
    const spells = (d.spells ?? {}) as { known?: unknown };
    return has(d.weapons, key) || has(d.armor, key) || has(d.feats, key) || has(d.species, key)
      || has(d.background, key) || has(spells.known, key);
  }).length;
}
```

```svelte
<script lang="ts">
  // The GM's homebrew: one tab per kind, a list with add/edit/delete, a form per entry, and file export/import.
  // Each entry is one room_content row; saving validates it with the same zod the readers use.
  import type { RulesetContext } from '../../core/types';
  import type { RoomStore } from '../../../sync/room.svelte';
  import TwoStepButton from '../../../ui/TwoStepButton.svelte';
  import { BLANK, FIELDS, KIND_LABEL } from './fields';
  import { fromHbText, HbFileError, planImport, toHbFile, type ImportPlan } from './file';
  import HbForm from './HbForm.svelte';
  import { HB_KINDS, HB_SCHEMAS, MAX_PER_KIND, rowKind, slugKey, type HbKind } from './kinds';
  import { brokenRows, srdFor } from './merge';
  import { getSrd } from '../index';
  import { usageCount } from './usage';

  let { store, ctx, onclose }: { store: RoomStore; ctx: RulesetContext; onclose: () => void } = $props();

  let tab = $state<HbKind>('weapon');
  /** The entry being edited: its row id (null = new), key, and a working copy of its data. */
  let editing = $state<{ id: string | null; key: string | null; data: Record<string, unknown> } | null>(null);
  let issues = $state<{ path: string; message: string }[]>([]);
  let message = $state('');
  let plan = $state<{ plan: ImportPlan; items: ImportPlan['add'] } | null>(null);
  let fileInput = $state<HTMLInputElement>();
  let panel = $state<HTMLElement>();
  $effect(() => panel?.focus());

  const srd = $derived(srdFor(ctx));
  const rows = $derived.by(() => {
    void store.contentVersion;
    return [...store.state.content.rows.values()].filter((r) => r.kind === rowKind(tab)).sort((a, b) => a.key.localeCompare(b.key));
  });
  const broken = $derived(new Set(brokenRows(ctx).map((b) => `${b.kind}/${b.key}`)));
  const characters = $derived.by(() => {
    void store.charactersVersion;
    return [...store.state.characters.rows.values()].map((c) => c.data);
  });
  const nameOf = (data: Record<string, unknown>) => String(data.name ?? '') || '(ไม่มีชื่อ)';

  function startNew() {
    message = '';
    issues = [];
    editing = { id: null, key: null, data: BLANK[tab]() };
  }
  function startEdit(r: { id: string; key: string; data: Record<string, unknown> }) {
    message = '';
    issues = [];
    editing = { id: r.id, key: r.key, data: structuredClone($state.snapshot(r.data)) as Record<string, unknown> };
  }

  async function save() {
    if (!editing) return;
    const p = HB_SCHEMAS[tab].safeParse($state.snapshot(editing.data));
    if (!p.success) {
      issues = p.error.issues.map((i) => ({ path: i.path.join('.'), message: i.message }));
      return;
    }
    if (!editing.key && rows.length >= MAX_PER_KIND) {
      message = `มี${KIND_LABEL[tab]}ครบ ${MAX_PER_KIND} ชิ้นแล้ว ลบชิ้นที่ไม่ใช้ก่อน`;
      return;
    }
    const key = editing.key ?? slugKey(String(p.data.name), rows.map((r) => r.key));
    await store.saveContent(rowKind(tab), key, p.data as Record<string, unknown>);
    editing = null;
    message = 'บันทึกแล้ว';
  }

  function exportFile() {
    const url = URL.createObjectURL(new Blob([JSON.stringify(toHbFile([...store.state.content.rows.values()]), null, 1)], { type: 'application/json' }));
    Object.assign(document.createElement('a'), { href: url, download: 'homebrew.json' }).click();
    setTimeout(() => URL.revokeObjectURL(url), 1000);
  }
  async function readFile(f: File) {
    message = '';
    try {
      const file = fromHbText(await f.text());
      const p = planImport(file, getSrd(), [...store.state.content.rows.values()]);
      plan = { plan: p, items: [...p.add, ...p.replace] };
    } catch (e) {
      message = e instanceof HbFileError ? e.message : 'อ่านไฟล์ไม่สำเร็จ';
    }
  }
  async function confirmImport() {
    if (!plan) return;
    for (const i of plan.items) await store.saveContent(i.kind, i.key, i.data);
    message = `นำเข้าแล้ว ${plan.items.length} ชิ้น`;
    plan = null;
  }
  function onKey(e: KeyboardEvent) {
    if (e.key === 'Escape') {
      e.stopPropagation();
      onclose();
    }
  }
</script>

  </footer>
</section>
```
